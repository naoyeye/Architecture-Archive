# Archello 支持与新增站点技能

1. 根据实际 project、相册、查看器 DOM 确认所属 story、原图及完整性信号。
2. 增加独立浏览器适配器，限定同源请求，保留取消、超时、导航变化检查。
3. 复用 schema version 1，按来源验证图片；接入 URL、CORS、控件与安装头。
4. 添加脱敏/合成测试、跨语言与 HTTP 回归；构建单文件脚本。
5. 将接入流程写入项目级 `.agents/skills/archive-add-site/SKILL.md`，同步文档与开发状态。

不修改用户归档，不重启服务，不进行付费翻译，不提交代码。Archello 原图必须来自查看器中明确的 S3 images URL，不从缩略图地址猜测。页面缺失、相册数量不符、跨项目或未知格式均显式失败。
