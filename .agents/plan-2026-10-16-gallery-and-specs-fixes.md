# Archello 分页相册与 ArchDaily 项目字段修复

- 日期：2026-10-16
- 状态：完成
- 目标：解决两个指定项目的采集失败，保持 schema version 1 与图片来源校验。

## 页面证据

- Living in Alpine Village 主故事 38574，`photos-videos-grid` 分页使用同 story 相册路径、`page` 和 `per-page` 参数。首屏位置 1–36，第二页 37–41；查看器显示 1 of 41，并明确提供 S3 原图。
- House at the Top of the Hill 的 `.submit_yourself` 入口复用 `.afd-specs__item`，不是 key/value 项目字段；共 15 张图库图片。

## 实施与验证

1. 分离相册单页解析与完整相册校验，逐页跟随页面提供的下一页链接；限定同源、story、category 与分页参数，校验页码连续、总位置连续、媒体 ID 唯一、上限和终止状态。
2. 全部清单完成后逐张校验查看器原图、媒体 ID 与总数，分页请求复用取消/超时与导航检查。
3. ArchDaily 仅跳过无字段标记的投稿入口；保留真实字段缺失报错及广告处理。
4. 增加正常与异常分页、取消/超时、投稿入口和真实缺失回归；运行 JS、Python 与构建检查。公开页面核对不等于下载/翻译端到端验收。
5. 更新脚本版本、构建产物、说明与开发状态；不修改归档数据或重启服务。

## 结果

- 已实现分页清单收集、页码与大小校验、位置连续性、媒体 ID 唯一性和上限；逐张查看器仍核对原图路径、媒体 ID 与总数。
- 投稿入口仅在没有 key/value 字段标记时排除，真实字段缺失继续报错。
- 64 项 JS、41 项 Python 测试、npm run check、git diff --check 通过；按通用与 JavaScript 相关规则自查无待修复问题。技能 review.sh 缺少其 lib/common.sh，正式脚本未运行成功，改为直接审查本次工作区差异。
- 实际公开页面核对相册 36+5 张、41 个唯一媒体 ID、首尾查看器原图与总数；ArchDaily 保留 13 个有效字段及 15 张图库图片。
- 脚本版本 2026-10-16.1；无后端变更。未调用真实翻译或执行完整归档。
